## Purpose of the Project
The purpose of this project is to develop a cross-platform screen sharing application that allows users to share their screens in real-time. The application is used when users use same machine. The application should be user-friendly, secure, and efficient, leveraging modern C++ features and the Qt framework for a seamless user experience.

## Features
- Real-time screen sharing
- Multi-platform support
- User authentication
- Users can not share their screen without permission
- Users can not use sudo command, and must not have elevated privileges.
